## Project Structure

The assignment is divided into three main tasks across three days:

### 🏠 Day 1: Responsive Home Page
- Built based on the provided Figma Design: **Frontend Challenge UI**
- Fully responsive design using CSS Flexbox and Grid.
- **Bonus Implemented:**
  - Code-splitting with **React Lazy Loading** and **Suspense** for faster load times.
  - Optimized assets and structure for performance.

### ✅ Day 2: Task Manager Section
- Functional task list with the following features:
  - Add/Delete tasks.
  - Mark tasks as completed.
  - Messages and warnings for user feedback.
  - All task data handled via **React local state**.
  - Fully responsive layout.

### 📬 Day 3: Contact Form Section
- Contact form includes the following fields:
  - Name (required)
  - Email (required with validation)
  - Phone Number (validated internationally)
  - Message (required)
- Built with **React Hook Form** for validation.
- Phone number validation using **libphonenumber-js**.
- Real-time inline validation feedback.
- Displays a success message on submission (form submission is simulated only).
